# Proposed tokens

Tokens the five components need that the Figma files do not hold yet. The one-pager says border widths, motion and elevation "aren't started"; a button cannot be built without a border width, a focus ring and a height.

They live here, not in Figma, because the Figma files must not be changed. Each follows the naming standard, carries a description and a reason, and is listed by the diff tool as "in code, not in Figma: proposed" until someone adds it to Figma or rejects it. Nothing here overrides a value Figma holds; that is what `../overrides.json` is for.
