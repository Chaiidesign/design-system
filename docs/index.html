Design system reference

Version 0.1.0. tokens, three components, written guidance for each, and checks that fail the build when a rule is broken.

Everything on this page is rendered from the token files. Change a value in tokens/, run npm run build, and the page and every component update.

Principles

Draft. These settle trade-offs; replace them with the product's own.

  1. Clear before clever. If a person has to think about the interface, the interface is in the way. Prefer the plain label, the standard control, the obvious place.
  2. Accessible by construction. Keyboard, focus, contrast and screen-reader behaviour are solved once in the component, so no product team has to solve them again.
  3. One decision, one place. Every colour, size and duration is a named token. If a value is typed twice, one of them is wrong.

Voice

Plain, direct and calm. Say what happened and what to do next. Sentence case everywhere. No exclamation marks, no blame, no jargon the person did not bring themselves. Tone shifts with the moment: brisk for routine actions, slower and more specific when something has gone wrong.

Colour

Two layers. Palette tokens are raw values. Semantic tokens name a purpose and point at a palette step; they are the only colours a component may use. A theme is a second set of pointers, so switching theme or brand touches one layer.

Type

A modular scale: 1rem base, each step 1.2 times the last. Body text uses font.size.md at line height 1.5 and is capped at measure.prose.

Space and shape

Spacing is a 4-point scale: the token number is the multiple of 4px. Use it for padding, gaps and margins.

Button

Starts an action: save, send, delete, open a dialog. Full guidance in components/button/button.md.

Use it when

  • The person is doing something: submitting, saving, confirming.
  • One primary button per view; the rest are secondary or ghost.

Do not use it when

  • The control goes to another page. Use a link.
  • The choice is on or off. Use a checkbox or switch.
  • Danger styling is wanted for anything that does not destroy data.

Accessibility

  • A real <button> with type set.
  • Focus ring is never removed.
  • Prefer aria-disabled with a visible reason over disabled.

Content

  • Verb plus object: "Save changes", not "OK".
  • Sentence case, no full stop, two or three words.

Field

A labelled single-line text input with an optional hint and error. Full guidance in components/field/field.md.

Type something that is not an email, then tab away.

Enter an email address, like name@example.com

Enter all 8 digits of the reference number

Use it when

  • The answer is short free text.

Do not use it when

  • The answer is one of a known set. Use radios or a select.
  • A placeholder would stand in for the label.

Accessibility

  • Visible label tied with for and id.
  • Hint and error linked with aria-describedby.
  • Invalid state adds border weight and text, not colour alone.

Content

  • Errors say what to do: "Enter an email address", not "Invalid input".

Callout

A short message set apart from the content around it. Full guidance in components/callout/callout.md.

Your plan renews on 1 March

You can change or cancel it any time before then.

Changes saved

Check your billing address

It does not match the address on your card.

There is a problem

Enter an email address to continue.

Use it when

  • The message applies to the whole section or page.

Do not use it when

  • The message is about one field.
  • There would be more than one in view.

Accessibility

  • Variants differ only by colour, so the title carries the meaning.
  • role="alert" only when inserted after an action.

For agents

The same rules people follow are written for machines and enforced by checks.

  • AGENTS.md: the short rule list for coding agents.
  • llms.txt: an index of every guidance file.
  • dist/tokens.resolved.json: every token with its purpose and value in each theme.
  • npm run check: rebuilds tokens, checks 36 colour pairings in both themes, and rejects CSS that uses a raw colour, a palette token or an unknown token.
